# 영어 플래시카드 (English Flashcard)

영어 공부를 위해 직접 만든 **단어·표현 암기용 플래시카드 웹앱**입니다.
AI를 활용해 제작했으며, 브라우저(모바일 포함)에서 바로 사용할 수 있고 PWA로 설치할 수도 있습니다.

> 스와이프로 배우고, 반복으로 기억하세요.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 스와이프 학습 | 카드를 탭해 뜻을 확인하고, 오른쪽(알아요) / 왼쪽(모르겠어요)으로 넘기기 |
| 퀴즈 모드 | 10문제 단위 객관식 퀴즈, 정답·오답 즉시 확인 |
| 복습 단어장 | "모르겠어요"·오답 단어가 자동으로 단어장에 모이고, 복습 필요 단어만 따로 학습 |
| 학습 통계 | 연속 학습일, 오늘 정확도, 누적 학습량, 이번 주 학습량, 최근 28일 학습 달력 |
| 카테고리 필터 | 주제별로 카드를 골라서 학습 |
| 단어 가져오기 | Excel(XLSX) · CSV · JSON 파일을 끌어다 놓아 여러 파일 한 번에 등록 |
| 기기 간 동기화 | 단어·학습 기록·단어장을 파일로 내보내고 다른 기기에서 가져오기 |
| 단어 관리 | 표현·뜻·예문 3개·카테고리를 직접 추가·수정 |
| 학습 알림 | 매일 알림 시간과 목표 카드 수 설정 (PWA 설치 후 브라우저 알림 허용 시) |

## 사용 방법

- GitHub Pages로 배포되어 있어 저장소 오른쪽 **About**의 링크로 바로 열 수 있습니다.
- 로컬에서는 `index.html`을 브라우저로 열면 됩니다.
- 학습 데이터는 브라우저(localStorage)에 저장되며, 다른 기기로 옮길 때는 **내보내기 → 가져오기**를 사용합니다.

## 기술

HTML · JavaScript · localStorage · SheetJS(Excel 읽기) · PWA · GitHub Pages

## 제작 배경

영어 표현을 꾸준히 외우기 위해, 내 단어 목록(Excel)을 그대로 불러와 반복 학습할 수 있는 도구를 AI와 함께 만들었습니다.
